# Store listing

Text to paste into App Store Connect and Play Console. Character limits are in brackets. Each field sits in a code block
so formatting tools keep its line breaks and it copies exactly.

Apple guideline 1.3: an app outside the Kids Category must not say "for kids" or "for children" in its metadata, so the
text says "family" and "all ages" instead. Keep it that way when editing.

- Privacy policy URL: https://nsargsyan996.github.io/blockaroo/privacy/
- Support / marketing URL: https://nsargsyan996.github.io/blockaroo/
- Contact email: blockaroo.support@gmail.com (both stores show it publicly)
- Category: **Games › Puzzle** on both stores. Secondary category on iOS: **Games › Family**.
- Price: free. Contains ads: yes. In-app purchases: none.

Armenian is offered by Google Play but not by App Store Connect, so on iOS the app ships with English and Russian
listings (the app itself still runs in Armenian).

## Google Play

**Target audience and content.** The app is child-directed in code, so pick the age groups honestly. Recommended: all
groups from "5 and under" (or "6–8") up to "18 and over". Any group under 13 puts the app under the Families policy:

- Ads SDK: Google AdMob is a Families self-certified SDK. ✔
- "Could your app unintentionally appeal to children?" N/A once children are selected.
- Teacher Approved: optional, leave it off for the first release.

**Ads.** Contains ads: yes.

**Data safety.** Based on Google's own disclosure for the Google Mobile Ads SDK
(developers.google.com/admob/android/privacy/play-data-disclosure). Check that page before submitting, since Google
updates it.

| Data type                                          | Collected | Shared | Purpose                                  |
| -------------------------------------------------- | --------- | ------ | ---------------------------------------- |
| Location › Approximate location (from IP)          | yes       | yes    | Advertising, Analytics, Fraud prevention |
| App activity › App interactions                    | yes       | yes    | Advertising, Analytics, Fraud prevention |
| App info and performance › Crash logs, Diagnostics | yes       | yes    | Analytics, Fraud prevention              |
| Device or other IDs                                | yes       | yes    | Advertising, Fraud prevention            |

- Is all data encrypted in transit? Yes.
- Can users request deletion? No account exists; answer "No" (data isn't tied to an identity).
- Device ID note: the `AD_ID` permission is blocked, so the advertising ID isn't read, but AdMob still uses an app-set
  ID for frequency capping and fraud prevention, which counts as "Device or other IDs".

**Content rating (IARC questionnaire).** Category: Game. No violence, fear, sex, language, drugs, gambling or simulated
gambling. No user interaction or chat, no sharing of location, no purchases of digital goods. Expected result: PEGI 3 /
ESRB Everyone.

**Government apps / Financial / Health / News**: no.

## App Store

**Age rating questionnaire.** Answer "None" everywhere, "No" to unrestricted web access, user-generated content,
messaging and gambling. Expected result: 4+. Do **not** choose the Kids Category: it bans most third-party ads, and
AdMob apps there are usually rejected.

**App Privacy ("nutrition label").** Based on Google's disclosure for the Google Mobile Ads SDK
(developers.google.com/admob/ios/privacy/data-disclosure):

| Data type                                                         | Linked to user | Used for tracking | Purpose                            |
| ----------------------------------------------------------------- | -------------- | ----------------- | ---------------------------------- |
| Location › Coarse location                                        | no             | no                | Third-party advertising, Analytics |
| Identifiers › Device ID                                           | no             | no                | Third-party advertising, Analytics |
| Usage data › Product interaction, Advertising data                | no             | no                | Third-party advertising, Analytics |
| Diagnostics › Crash data, Performance data, Other diagnostic data | no             | no                | Analytics                          |

"Used for tracking" is no because the app never asks for App Tracking Transparency and doesn't read the IDFA.

**Export compliance.** Already answered in `app.config.ts` (`ITSAppUsesNonExemptEncryption: false`).

**App Review notes.** Suggested text:

> Hoppy Blocks has no login. Ads come from Google AdMob, are tagged child-directed and under the age of consent, limited
> to G-rated content and non-personalized. Rewarded video is opt-in ("Keep playing" on the game-over card).
